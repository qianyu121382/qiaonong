# 巧侬企业官网

本仓库用于重做 `zgqnht.com` 巧侬企业官网。

已完成旧站公开页面的第一版只读调研，结果见 `docs/旧站公开页面调研.md`。旧站 HTTP 当前可以访问，但 HTTPS 证书异常；部分结构结论来自 2025 年公开历史快照，仍需与用户逐块确认。

项目已开始按照八阶段开发流程逐项确认，当前项目目标与前端还原边界见 `docs/项目定义.md`。

现有阿里云服务器配置、同机部署边界及巧侬独立运行要求见 `docs/服务器配置与部署约束.md`。

第一版包含公开前端、后端和简单管理员后台，不采用 Wagtail，也不需要内容预览与发布工作流。具体技术栈、页面清单和数据维护范围仍按项目流程逐块确认。

当前已进入工程准备阶段，建立了 `frontend/`、`admin-frontend/` 和 `backend/` 的最小可运行基线，但尚未开始产品或页面业务模块开发。本地启动与检查方式见 `docs/开发与验证说明.md`。

婵泉项目只能作为开发流程参考。巧侬必须使用独立的代码仓库、后台、数据库、环境变量、媒体目录、部署服务和备份，不得复制或混入婵泉的品牌内容、图片、账号或生产数据。
