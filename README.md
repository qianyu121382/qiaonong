# 巧侬企业官网

本仓库用于重做 `zgqnht.com` 巧侬企业官网。

第一版已经正式上线并进入生产维护阶段。正式官网为 `https://zgqnht.com/`，管理后台位于 `/manage/`；最新状态、线上内容基线和下一步见 `docs/当前进度与下一步.md`。

项目最初按照八阶段开发流程逐项确认，已确认的项目目标与前端还原边界见 `docs/项目定义.md`。

现有阿里云服务器配置、同机部署边界及巧侬独立运行要求见 `docs/服务器配置与部署约束.md`。

巧侬专用安全 CD 已完成服务器安装、首次真实部署和自动部署验收，信任边界与冻结范围见 `docs/CD方案与接入说明.md`。

第一版采用 Vue 3 + Vite 公开前端、独立 Vue 管理后台、Django/DRF 后端和 PostgreSQL，不采用 Wagtail，也不提供内容审核发布工作流。

公开站、管理员后台、后端 API、旧站迁移、HTTPS、SEO、备案和独立部署均已落地。历史部署前基线见 `docs/第一版实现与部署前检查.md`；本地启动与检查方式见 `docs/开发与验证说明.md`。

婵泉项目只能作为开发流程参考。巧侬必须使用独立的代码仓库、后台、数据库、环境变量、媒体目录、部署服务和备份，不得复制或混入婵泉的品牌内容、图片、账号或生产数据。
