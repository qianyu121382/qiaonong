# 巧侬总体设计与工程准备

## 阶段说明

本文对应八阶段开发流程中的第 4 阶段“总体设计和工程准备”，内容按用户确认结果逐项补充。

## 已确认技术路线

项目采用前后端分离结构：

- 公开前端：Vue 3 + Vite。
- 管理员后台：独立的 Vue 3 + Vite 应用。
- 后端：Django + Django REST Framework。
- 数据库：PostgreSQL。
- 图片：由后端管理上传信息，文件保存在巧侬独立媒体目录。
- 生产服务：Nginx、Gunicorn、systemd 和 Certbot。

第一版不采用 Wagtail，也不使用 Django Admin 作为交付给管理员的主要后台界面；不提供草稿预览、审核发布和额外 SEO 管理流程。

## 项目目录边界

```text
qiaonong/
├── frontend/        # 公开 Vue 前端
├── admin-frontend/  # Vue 管理员后台
├── backend/         # Django/DRF 后端
├── deploy/          # 巧侬独立部署配置模板
├── docs/            # 项目文档
├── migration/       # 旧站公开迁移输入与清单
└── scripts/         # 项目级辅助脚本
```

## 与婵泉的关系

- 可以参考婵泉已经验证过的前后端组织方式、开发顺序和部署经验。
- 不复制婵泉品牌内容、图片、业务数据、账号、密钥和生产环境变量。
- 不让巧侬依赖婵泉仓库中的代码或运行文件。
- 两个项目即使位于同一台服务器，也使用独立应用目录、虚拟环境、数据库用户、数据库、Gunicorn 服务与 socket、Nginx 站点配置、媒体目录、静态目录、日志和备份。
- 服务器可共用系统级 Nginx 和 PostgreSQL 进程，但项目级配置与数据必须隔离。

## 第一版模块及职责

### `core`

- 提供健康检查。
- 处理管理员登录、退出和会话状态。
- 提供各业务模块共同使用的少量基础能力。
- 不承载产品或页面内容数据。

### `content`

- 拥有首页展示内容。
- 拥有品牌介绍。
- 拥有联系方式。
- 拥有确认保留的政策页内容。

### `catalog`

- 拥有产品分类和层级关系。
- 拥有产品、产品图片、排序和上下架状态。
- 提供公开产品列表、详情和站内搜索。
- 提供管理员维护分类与产品所需的管理接口。

### Vue 应用边界

- `frontend/` 只调用公开只读 API，不包含管理功能。
- `admin-frontend/` 登录后调用管理 API，不承担公开页面展示。
- 两个 Vue 应用均不直接访问数据库或媒体文件系统。
