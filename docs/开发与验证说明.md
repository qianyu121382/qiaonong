# 巧侬开发与验证说明

## 工程基线

- Python 3.12
- Django 5.2 LTS
- Django REST Framework 3.16
- PostgreSQL 16
- Node.js 24 LTS
- Vue 3、Vue Router、Vite
- npm 与 `package-lock.json`
- uv 与锁定的 Python 依赖文件

## 目录

- `frontend/`：公开官网，开发端口 `5173`。
- `admin-frontend/`：管理后台，开发端口 `5174`，生产基础路径 `/manage/`。
- `backend/`：Django/DRF API，开发端口 `8000`。
- `deploy/`：可提交但不含凭据的部署配置模板。

## 前端命令

公开官网和管理后台分别在各自目录运行：

```bash
npm ci
npm run dev
npm run build
```

两个 Vite 开发服务器均把 `/api` 代理到 `http://127.0.0.1:8000`。

## 后端命令

先为巧侬创建独立 PostgreSQL 开发角色和数据库，再复制 `backend/.env.example` 为不提交的 `backend/.env`。

```bash
cd backend
uv venv --python 3.12
uv pip install --python .venv/bin/python -r requirements/dev.lock.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver
```

检查命令：

```bash
.venv/bin/python manage.py check
.venv/bin/python manage.py makemigrations --check --dry-run
.venv/bin/python manage.py test
```

本机 PostgreSQL 开发角色没有创建测试数据库的权限时，可使用仅供测试的内存 SQLite 配置：

```powershell
python manage.py test --settings=config.settings.test
```

该配置不会读取或修改本地开发数据库，生产环境仍固定使用独立 PostgreSQL。

健康检查：`GET /api/health/`。

### 当前 Windows 本地环境

用户已确认，当前电脑可以使用现有 `chanquan-django` Conda 环境运行巧侬后端。它只作为共享的 Python 3.13 解释器和依赖工具环境，主要依赖版本与巧侬锁文件一致。

```powershell
conda activate chanquan-django
cd E:\MyCode\Code\qiaonong\backend
python manage.py check
python manage.py runserver
```

巧侬不得读取或复用婵泉的 `.env`、数据库、数据库角色、媒体目录、管理员账号和业务数据。本地解释器可以共用，项目配置和数据仍必须隔离。

## 环境边界

- 开发默认使用 `config.settings.development`。
- 生产使用 `config.settings.production`，缺少正式密钥或允许域名时拒绝启动。
- `.env`、数据库数据、媒体目录、构建产物和日志均不提交。
- 巧侬不得使用婵泉的数据库、账号、环境变量、媒体、服务或备份。
