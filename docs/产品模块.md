# 巧侬产品模块

## 本轮范围

本文记录第 5 阶段首个开发块：产品分类、产品、产品图片，以及对应的公开和管理 API。公开页面与 Vue 管理界面将在后续小块中接入这些接口。

## 数据边界

### 产品分类

- 最多两级，已有下级的一级分类不能改成二级分类。
- 产品可以直接归属一级分类，也可以归属二级分类。
- 包含名称、稳定 `slug`、上级分类、简介、栏目图、排序、启停状态和可选旧站 ID。
- 存在下级分类或关联产品时禁止删除。
- 一级分类停用后，其下级分类和产品均不在公开 API 中显示。

### 产品

- 包含分类、名称、稳定 `slug`、标签、摘要、规格、详情正文、封面图、悬停图、排序、首页推荐、上下架状态和可选旧站 ID。
- 新产品默认下架，避免资料未完成时意外公开。
- 分类删除采用保护规则，不级联删除产品。

### 产品图片

- 一个产品可以维护多张详情图片，并单独设置替代文字和排序。
- 删除产品时，其相册记录一并删除；媒体文件的长期清理策略在数据迁移与运维阶段单独处理。
- 上传仅接受 JPG、PNG 和 WebP，单张不超过 10 MB，宽高均不超过 8000 像素。

## 公开 API

- `GET /api/catalog/categories/`：启用的一级分类及其启用的二级分类。
- `GET /api/catalog/categories/{slug}/`：启用分类详情。
- `GET /api/catalog/products/`：公开产品列表。
- `GET /api/catalog/products/{slug}/`：公开产品详情及相册。

产品列表支持：

- `category={slug}`：按分类筛选；选择一级分类时同时包含其二级分类产品。
- `search={关键词}`：搜索产品名称、标签、摘要和规格。
- `featured=true`：只返回首页推荐产品。

公开接口只返回已上架、所属分类启用且上级分类启用的产品。

## 管理 API

- `/api/admin/catalog/categories/`
- `/api/admin/catalog/products/`
- `/api/admin/catalog/product-images/`

三组接口均提供标准新增、读取、修改和删除操作，只允许已登录且具有后台权限的 Django 管理员访问。写操作继续受 Session 与 CSRF 保护；管理员登录接口属于后续 `core` 认证小块。
