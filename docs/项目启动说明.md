# 巧侬项目启动说明

## 已知信息

- 旧站域名：`zgqnht.com`
- 项目性质：企业展示官网重做
- 开发者熟悉 Python、Django、Java、Scala、Vue 和 React。
- 第一版已正式上线，包含 Vue 公开前端、Vue 管理后台、Django/DRF 后端和 PostgreSQL，不采用 Wagtail。
- 巧侬与婵泉必须保持完全独立。
- 婵泉项目的开发过程可以作为流程参考，但巧侬的网站结构、视觉、内容和后台需求必须重新调研。
- 已部署在现有阿里云轻量应用服务器上；物理服务器与婵泉共用，但代码、进程、数据库、环境变量、媒体、日志和备份保持独立，详见 `docs/服务器配置与部署约束.md`。

## 当前状态

- 旧站调研、迁移和第一版开发已经完成。
- 正式站：`https://zgqnht.com/`；根域名为规范地址，HTTP 与 `www` 统一跳转。
- 管理后台维护产品分类、产品、首页轮播和公司信息。
- 公开站提供产品分类、产品详情、站内搜索、品牌介绍和联系方式，不增加购买、会员、留言或新闻模块。
- HTTPS、ICP 备案、公安联网备案、SEO 和安全自动部署已经投入生产。
- 最新提交、线上数据和待办事项见 `docs/当前进度与下一步.md`。

## 后续工作

- 逐页精修和真实设备验收。
- 持续核验产品内容、图片和功效表述。
- 观察线上运行、搜索引擎收录和服务器资源。
- 完善媒体定期备份、保留策略、异机备份和恢复演练。
