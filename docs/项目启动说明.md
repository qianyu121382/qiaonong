# 巧侬项目启动说明

## 已知信息

- 旧站域名：`zgqnht.com`
- 项目性质：企业展示官网重做
- 开发者熟悉 Python、Django、Java、Scala、Vue 和 React。
- 后台技术方向已确认采用 Wagtail；具体数据模型和管理范围待旧站调研后逐块确定。
- 巧侬与婵泉必须保持完全独立。
- 婵泉项目的开发过程可以作为流程参考，但巧侬的网站结构、视觉、内容和后台需求必须重新调研。

## 尚未确认

- 旧站当前是否可以正常访问及其完整页面范围。
- 是否存在旧站管理员后台，以及是否需要只读查看。
- 哪些公开内容需要完整迁移。
- 哪些内容固定在前端，哪些内容需要客户后台维护。
- 是否需要产品、新闻、留言、搜索、分页或其他动态模块。
- 前端采用 Vue、Nuxt、React 或其他方案。
- 客户管理后台的具体范围。
- 域名、服务器、备案与上线现状。

## 第一项任务

只读访问旧站公开页面，整理以下内容并写入中文文档：

- 一级与二级导航
- 独立 URL 和页面内锚点
- 每个页面的主要视觉区块与组件
- 桌面端和手机端差异
- 产品、新闻、联系表单等可能需要动态化的模块
- 图片和文字迁移规模
- 旧站异常、失效链接及不应照搬的内容

调研阶段不修改旧站、不提交表单、不开始大规模编码。
