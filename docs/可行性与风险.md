# 巧侬第一版可行性与风险

## 阶段说明

本文对应八阶段开发流程中的第 3 阶段“验证第一版是否可行”。本阶段只识别足以影响第一版范围或上线的现实约束，不提前展开技术架构设计。

## 已确认条件

- 开发与后续维护人员：用户本人一人。
- 交付节奏：尽快上线。
- 当前目标上线日期：2026-08-09（今天）。
- 网站功能范围简单，以产品展示和简单管理员后台为核心。
- 自有服务器已经准备好，用户具备服务器登录和域名 DNS 修改权限。
- 当前先开发并验证项目自身，部署工作留到项目可运行后处理。
- 第一版获准从旧站公开页面迁移现有文字和图片，后续由管理员在新后台修正或替换。
- 服务器公网带宽为 200 Mbps，无月流量限制；服务器还承载另一个项目，当前无需为此额外扩大第一版范围。

## 当前判断

功能本身规模较小，但仓库尚无业务代码。服务器、域名权限和公开站迁移素材已经具备；当天完整上线是否可行，接下来主要取决于工程实现、内容结构化整理、视觉还原和部署验证进度。

## 旧站公开素材验证结果

2026-08-09 已完成受限只读抓取，只遍历首页、公开栏目页和公开产品详情页，不访问后台、不提交表单，并排除可能改变旧站状态的缓存链接。

- 公开页面共 84 个：首页 1 个、栏目/内容页 33 个、产品详情页 50 个。
- 保存静态资源 180 个，其中图片 174 张、JavaScript 5 个、CSS 1 个。
- 原始资源约 69.42 MiB，按内容去重后约 35.55 MiB。
- 发现 8 组重复资源，重复内容约 33.87 MiB。
- 最终抓取错误为 0；文件、哈希和图片格式完整性检查均通过。
- 原始页面、提取文字、资源和逐项清单保存在 `migration/legacy-site/`。

由此确认公开素材足以作为第一版迁移输入。图片较多但总体规模可控；后续仍需在总体设计阶段确定去重、压缩、缓存和交付方式。

## 风险分类

### 第一版开发与上线前必须满足

- 管理员登录和后台接口具备基本安全保护。
- 生产环境正确启用 HTTPS。
- 巧侬与同服务器上的其他项目使用独立进程、配置、数据库、媒体目录和备份。
- 上线前具备最低限度的数据与媒体备份、恢复方式。

### 现在考虑兼容、具体处理可在实现或部署阶段完成

- 旧 URL 是否需要重定向兼容。
- 图片去重、压缩、浏览器缓存和交付方式。
- 旧站主体、备案、联系方式和产品表述的最终核验。

### 不影响第一版方向的后续优化

- 在真实访问数据出现后再评估 CDN 或更复杂的图片处理服务。
- 根据运行数据继续优化缓存、监控和资源占用。

## 待验证条件

- 新站 HTTPS 证书的签发条件。
- 旧 URL 是否需要重定向兼容。
- 备份与恢复的最低要求。

## 阶段状态

当前没有发现足以推翻第一版范围或总体方向的关键风险。八阶段开发流程中的第 3 阶段“验证第一版是否可行”已完成；尚未确定的兼容与部署事项已分类，可在后续对应阶段处理。
