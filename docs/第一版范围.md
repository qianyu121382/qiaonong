# 巧侬网站第一版范围

## 阶段说明

本文对应八阶段开发流程中的第 2 阶段“确定第一版范围”，内容由用户逐项确认。

## 访客使用场景

第一版中，公开访客可以：

- 浏览首页。
- 浏览品牌介绍。
- 通过一级、二级分类浏览产品。
- 查看产品详情。
- 查看联系方式。
- 查看需要保留的政策页面。
- 使用顶部站内搜索。

除上述场景外，不主动增加旧站没有的访客功能。

## 管理员使用场景

第一版提供简单管理员后台。管理员登录后可以：

- 维护首页内容。
- 维护品牌介绍。
- 维护联系方式和需要保留的政策页。
- 维护产品分类。
- 新增、编辑、排序和上下架产品。
- 上传和更换页面及产品图片。

第一版不采用 Wagtail，不提供草稿预览、审核发布流程或额外 SEO 管理功能，也不设计复杂角色和权限体系。

## 第一版核心完整流程

管理员在后台新增或修改产品并保存，访客随后可以在对应分类中找到该产品并查看完整详情。

这条流程贯穿管理员后台、后端数据保存和公开前端展示，是第一版最重要的端到端验收主线。

## 范围分类

### 第一版必须实现

- 本文已经确认的访客使用场景。
- 本文已经确认的管理员使用场景。
- 管理员维护产品、访客浏览产品的核心完整流程。

### 后续可能实现

当前留空。项目不预设第二版功能，未来出现新需求时重新评估。

### 当前明确不实现

- 在线购买、支付和订单。
- 会员、经销商及员工系统。
- 在线留言或询盘。
- 新闻、招聘、门店等旧站没有的栏目。
- 第三方业务系统对接。
- 复杂角色和权限体系。
- 额外 SEO 管理功能。
- 草稿预览、审核和发布工作流。

## 核心流程验收标准

- 管理员可以成功登录后台。
- 管理员可以新增、编辑、排序、上下架产品，并上传产品图片。
- 保存后的数据正确持久化，刷新页面或重启服务后不会丢失。
- 上架产品出现在正确的产品分类和产品详情页中。
- 下架产品不再对公开访客显示。
- 桌面端和手机端都能正常浏览产品内容。
