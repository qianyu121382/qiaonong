# 旧站公开内容迁移源

本目录由 `scripts/capture_legacy_site.py` 从 `http://www.zgqnht.com/` 的公开页面只读抓取。

- `pages/`：公开页面原始 HTML 的 UTF-8 副本。
- `text/`：从页面提取的可读文字，便于核对和后续整理。
- `assets/`：页面直接引用以及 CSS 继续引用的同域静态资源。
- `manifest.json`：页面、资源、哈希、错误和重复文件清单。

抓取器只遍历首页、公开栏目页和公开产品详情页，不访问后台、不提交表单，并排除 `/index/cache` 等非内容页面。

这些文件是迁移输入，不代表内容已经核验。主体名称、备案信息、联系方式、政策文本、产品功效表述和图片版权仍需在正式上线前确认。

## 2026-08-09 抓取结果

- 公开页面：84 个，包括首页 1 个、栏目/内容页 33 个、产品详情页 50 个。
- 静态资源：180 个，包括 JPG 110 张、PNG 64 张、JavaScript 5 个、CSS 1 个。
- 资源原始体积：约 69.42 MiB。
- 按 SHA-256 识别出 8 组重复资源；按内容去重后约 35.55 MiB，重复内容约占 33.87 MiB。
- 抓取错误：0。
- 完整性检查：页面及清单文件无缺失，资源哈希全部匹配，174 张图片均能识别为有效图片文件。

详细逐项记录见 `manifest.json`。
